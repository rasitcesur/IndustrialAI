# CV Atlas MIL

CV Atlas MIL is a research system for casting-surface inspection based on
co-located grayscale intensity, morphology, and normal-reference atlas evidence.
It uses a five-expert ensemble with spatial multiple-instance learning.

For scientific methodology, limits, installation, and evaluation, see
[README.md](README.md) or [README_TR.md](README_TR.md).
